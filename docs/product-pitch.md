# Продуктовый питч

## Проблема
Люди часто договариваются о встречах в чатах вручную: предлагают время, уточняют место, следят за занятыми слотами и отдельно пишут тем, кому эти слоты доступны. Из-за этого договорённости теряются, а согласование занимает лишнее время.

## Целевая аудитория
Пользователи Telegram, которые регулярно договариваются о встречах с разными людьми или группами людей.

## Идея решения
Бот, в котором пользователь создаёт временные слоты и указывает, кому они доступны: конкретному человеку или категории пользователей.

Каждый слот может быть занят только одним человеком. Если слот доступен категории, его может занять любой один пользователь из этой категории.

Владелец слота получает заявку на бронирование и может подтвердить или отклонить её.

## Бизнес-сценарии
- добавление пользователя в контакты
- объединение контактов в категории
- создание набора слотов и настройка:
  1) даты и времени
  2) места встречи
  3) описания
  4) получателя: конкретного контакта или категорию
  5) лимита на количество слотов из этого набора, которые может занять один пользователь
- просмотр доступных слотов
- бронирование слота, можно предложить своё место и добавить комментарий
- подтверждение брони владельцем, можно предложить другое место
- согласование альтернативного места, если один из участников предложил свой вариант
- отмена брони
- удаление категории
- настройка уведомлений:
  1) слот заняли
  2) бронь слота отменили
  3) контакт опубликовал доступный слот
  4) наступил день встречи

## Критерий готовности MVP

Пользователь может создать набор слотов для категории, другой пользователь из этой категории может занять один свободный слот, после чего слот блокируется для остальных, а владелец может подтвердить или отклонить бронь.

## Основные сущности

- User — пользователь бота. Может создавать слоты, добавлять контакты и бронировать доступные ему слоты.
- Contact — связь между пользователем и добавленным им контактом.
- Category — группа контактов пользователя, которой можно открыть доступ к набору слотов.
- SlotSet — набор слотов с общими настройками: получатель, место, описание и лимит бронирований.
- Slot — конкретный временной интервал, который может занять максимум один пользователь.
- Booking — заявка или подтверждённая бронь конкретного слота.
- NotificationSettings — настройки уведомлений пользователя.

## Ключевые правила

- Один слот может быть занят максимум одним пользователем.
- Категория определяет доступ к слоту, а не коллективную бронь.
- После заявки на бронь слот временно блокируется для остальных пользователей.
- Владелец слота может подтвердить или отклонить бронь.
- Пользователь может бронировать только слоты, доступные ему напрямую или через категорию.
